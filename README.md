 🏥 Remote Telemedicine Platform

A modern web-based platform that enables seamless communication between patients and healthcare providers, allowing remote consultations, appointment booking, and medical data management.

---

## 🚀 Features

* 📅 Appointment scheduling system
* 💬 Real-time doctor–patient interaction
* 🗂️ Secure medical records management
* 🔐 User authentication (patients & doctors)
* 📱 Fully responsive UI

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite, HTML, CSS, JavaScript
* **Backend:** Node.js, Express
* **Database:** MongoDB

---

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/GurmeharSingh07/Remote-Telemedicine-Platform.git
cd Remote-Telemedicine-Platform
```

---

### 2. Install dependencies

```bash
npm install
```

---

### 3. Run the development server

```bash
npm run dev
```
